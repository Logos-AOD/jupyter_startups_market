# Исследование рынка стартапов и венчурных инвестиций

Проект направлен на анализ венчурного финансирования стартапов: выявление устойчивых закономерностей и оценку перспектив работы на рынке через приобретение и развитие бизнесов. На основе проведённого анализа необходимо определить отрасль, наиболее перспективную для инвестирования, и выбрать наиболее подходящий тип финансирования для заказчика.

**Цель исследования** — провести исследовательский анализ рынка стартапов и выработка рекомендаций по инвестированию на 2015 год.

## Задачи исследования

### Предобработка данных

1. Загрузить данные.
2. Изучить структуру данных, типы, пропуски, соответствие описанию.
3. Провести предобработку данных:
   - корректировка типов данных;
   - обработка пропущенных значений;
   - поиск и удаление дубликатов;
   - нормализация текстовых столбцов;
   - создание дополнительных признаков.
  
### Исследовательский анализ

- Провести предобработку данных, убрать дубликаты и пропуски, проверить корректность числовых и временных значений.
- Выделить группы компаний по срокам финансирования и сравнить их по количеству и объёму инвестиций.
- Классифицировать сегменты рынка на массовые, средние и нишевые и учесть это в дальнейшем анализе.
- Определить типичные и аномальные значения объёмов финансирования, исключить выбросы и ограничить период исследования.
- Сравнить популярность и объёмы разных типов финансирования.
- Проанализировать динамику раундов и объёмов инвестиций по годам, а также изменения в массовых сегментах рынка.
- Рассчитать долю возврата средств для разных типов финансирования и оценить её устойчивость.
- Подвести итоговые выводы и дать рекомендации, куда и каким образом было бы целесообразно инвестировать, если бы на дворе был 2015 год.

## Данные

Источник — открытые исторические данные о венчурных инвестициях.  
Таблицы: 
* `investments` — информация о компаниях и состоявшемся финансировании (название компании, ссылка на сайт, категория, общий объём привлечённых инвестиций, текущий статус, регион, код штата).
* `returns` — дополнительная статистика по возвратам средств.
